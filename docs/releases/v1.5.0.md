# EduSystem v1.5.0

Primeira versão pública completa do EduSystem Desktop.

## Destaques

- aplicativo Windows portátil com frontend e backend integrados;
- nova identidade visual e ícone oficial do EduSystem;
- banco SQLite criado e migrado automaticamente;
- dashboard avançado e relatórios PDF profissionais;
- gestão de alunos, turmas, matérias, cursos, escolas e universidades;
- notas, frequência e acompanhamento pedagógico;
- registros ativos/inativos com restauração;
- quadro branco avançado com desenho, formas, conectores, textos, post-its, imagens e pastas;
- perfis e permissões para direção, coordenação, professores, secretaria e responsáveis;
- importação Excel/CSV e pacotes de transferência EduSystem.

## Banco de dados

O banco é criado na primeira abertura em:

```text
C:\EduSystem\dados\database.sqlite
```

Para visualizar, use **DB Browser for SQLite**. O arquivo `LEIA-ME-BANCO-DE-DADOS.md` anexado ao release contém instruções de backup e os links oficiais. IBExpert não é compatível com o banco SQLite do EduSystem.

## Arquivos do release

- `EduSystem-Portable-1.5.0.exe`: aplicativo portátil Windows x64;
- `SHA256SUMS.txt`: hash para conferência de integridade;
- `EduSystem-Logo-1.5.0.png`: marca oficial em PNG transparente;
- `LEIA-ME-BANCO-DE-DADOS.md`: instruções do SQLite e DB Browser.
